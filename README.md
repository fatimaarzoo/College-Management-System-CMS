# 🎓 College Management System (FastAPI)

## 📌 Overview

The **College Management System** is a backend application built using **FastAPI** that manages core college operations such as students, faculty, courses, attendance, and results. It provides a set of RESTful APIs for efficient data handling and can be integrated with any frontend. Data Validation and Error Handling done with structured schemas and status codes.

---

## 🚀 Features

- 👨‍🎓 **Student Management**
  - Create, update, delete, and view student records  

- 👩‍🏫 **Faculty Management**
  - Manage faculty details  
  - Assign courses to faculty  

- 📚 **Course Management**
  - Add and manage courses  
  - Link students and faculty to courses  


---

## 🛠️ Tech Stack

- **Backend:** FastAPI (Python)  
- **API Documentation:** Swagger UI (auto-generated via OpenAPI)  
- **Database:** MySQL
- **ORM:** SQLAlchemy   
- **Server:** Uvicorn
-  **Library:** Pydantic
